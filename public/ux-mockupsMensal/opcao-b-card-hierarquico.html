Hierarquia por Zona

  • Zona 1 (header): card-name + status-badge + card-value em flex justify-between
  • Zona 2 (meta): string unica com separadores · em text-xs text-slate-500
  • Zona 3 (actions): hover-reveal com opacity 0 → 1 e max-height 0 → 44px
  • Zona 4 (edit): visivel apenas com data-expanded=true, grid 6-col

Status System

  • Pago: border-l emerald-400 + badge emerald + texto "Pago"
  • Parcial: border-l amber-500 + badge amber + texto "Parcial · R$ X"
  • Pendente: border-l slate-700 + badge slate + texto "Pendente"
  • Borda left = 3px, sempre visivel, canal primario de scanning vertical

Tokens Criticos

  • Card BG: bg-white/5 hover bg-white/[0.08]
  • Card radius: rounded-[1.25rem] (20px)
  • Card padding: p-[0.85rem_1.1rem]
  • Card gap: gap-[0.55rem] (8.8px) entre cards
  • Value: text-lg font-bold tabular-nums text-cyan-300
  • Name: text-[0.95rem] font-semibold text-white truncate
